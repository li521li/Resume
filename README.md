## 🛠️ 技术实现
- **纯原生技术栈**：HTML5 + CSS3 + 原生 JavaScript，无任何前端框架依赖，单文件即可运行
- **主题系统**：CSS 变量驱动的明暗双主题，支持本地记忆用户偏好，刷新不丢失
- **可视化**：原生 SVG 绘制技能雷达图，零图表库依赖，主题色自动跟随系统切换
- **交互动效**：滚动入场动画、数字递增动画、时间轴滚动高亮、项目卡片展开收起
- **响应式布局**：Grid + Flex 自适应方案，完美适配移动端到桌面端全尺寸屏幕
- **部署方式**：GitHub Pages 静态托管，零成本一键上线，支持自定义域名
